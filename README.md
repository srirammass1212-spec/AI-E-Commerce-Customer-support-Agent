# AI E-Commerce Customer Support Agent

## Project Description
The AI E-Commerce Customer Support Agent is a web-based application that helps customers get support for their e-commerce queries. It is developed using Python, Streamlit, and SQLite.

## Features
- Customer support interface
- Customer query handling
- Conversation management
- SQLite database integration
- Interactive web application

## Technologies Used
- **Python** – Application logic
- **Streamlit** – User interface
- **SQLite** – Database management

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd AI-E-Commerce-Customer-Support-Agent
   ```

3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.
